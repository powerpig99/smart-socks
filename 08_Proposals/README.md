## Quick Start

### 1. Feature Importance Analysis
```bash
cd 08_Proposals/feature_importance
python feature_importance.py \
    --model ../../05_Analysis/smart_socks_model.joblib \
    --output ./results/
```

**Output:**
- `edge_feature_config.json` — Minimal feature set for ESP32 deployment
- `feature_importance_analysis.png` — Visualization
- Typically reduces 100 features → 15-25 (60-75% reduction)

### 2. Unknown Class Detection
```bash
cd 08_Proposals/unknown_class

# Train with confidence threshold
python unknown_class.py --train \
    --features ../../03_Data/features/features_all.csv \
    --method confidence --threshold 0.6

# Or train with novelty detection
python unknown_class.py --train \
    --features ../../03_Data/features/features_all.csv \
    --method novelty --contamination 0.1
```

**Critical:** Collect data for unknown activities:
- jumping, running_in_place, random_movement, stretching

### 3. Automated Data Validation
```bash
cd 08_Proposals/auto_validation
# See README.md for integration with collector.py
```

## Design Principles

1. **No breaking changes** — All proposals are additive
2. **Backward compatible** — Existing code continues to work
3. **Testable** — Each proposal includes evaluation methods
4. **Documented** — Usage examples and expected outcomes
